# Deluxe Saloon 2.0 💈📻

An interactive, ambient web experience bringing retro regional barber shop culture and curated music from across India to life.

## 🌟 Features

- **🏪 Animated Rolling Shop Shutters**: Gesture-controlled (drag up on desktop / swipe up on mobile) region-specific shop shutters featuring local language typography, city landmark artwork, and live weather integration.
- **🌆 4 Distinct Regional Hubs**:
  - 🏙️ **Mumbai** (`मराठी`) — Warm coastal vibes, Bollywood classics, and live weather.
  - 🏛️ **Delhi** (`हिंदी`) — Winter retro tunes, Qutub Minar artwork, and street radio chatter.
  - 🌴 **Chennai** (`தமிழ்`) — Sunlight, Kollywood hits, and Tamil barber shop dialogue.
  - 🚋 **Kolkata** (`বাংলা`) — Rainy streetscape, vintage Bengali melodies, and tea shop banter.
- **🌧️ Dynamic Rain & Weather Overlay**: Live Open-Meteo API weather synchronization with custom canvas rain physics.
- **💬 Diegetic Barber Shop Chatter**: Region-matched speech bubbles & floating customer comments.
- **🔀 Fisher-Yates Session Shuffle**: Fresh playlist order on every visit.
- **📱 Fully Responsive**: Tailored layouts for desktop, tablet, and mobile browsers.

## 🚀 Getting Started

First, install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🛠️ Built With

- [Next.js 15+](https://nextjs.org/) (App Router & Turbopack)
- [React 19](https://react.dev/)

- [Open-Meteo API](https://open-meteo.com/) (Live Weather)
